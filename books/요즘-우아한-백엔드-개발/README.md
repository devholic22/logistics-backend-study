# 요즘 우아한 백엔드 개발

> [물류·백엔드 학습 노트](../README.md)

이 책은 모든 장을 기록하지 않고, WMS·OMS의 입고·재고·출고와 백엔드 시스템의 설계·운영에 직접 연결되는 사례를 선별해 정리한다.

## 선별 기준

- WMS·OMS의 입고·재고·출고·센터 운영을 직접 다루는가
- 물류 도메인의 경계와 상호작용을 보여주는가
- WMS 핵심 기능을 안전하게 변경·배포하는 방법을 담고 있는가
- 예외 처리·동시성·관측성처럼 백엔드 운영의 신뢰성을 높이는 판단을 담고 있는가
