> [아키텍트 첫걸음](../README.md)

## 이 장에서 확인할 것

- 소프트웨어가 사업의 본체가 된 환경에서 IT 전략을 어떻게 나눠야 하는가
- 변화에 적응하는 능력(어질리티)이 왜 아키텍처의 문제인가
- 아키텍처가 왜 중요하고, 아키텍트는 무엇을 하는 사람인가
- 아키텍처 설계 방식이 과거와 지금 어떻게 달라졌는가
- 아키텍트에게 요구되는 자질
