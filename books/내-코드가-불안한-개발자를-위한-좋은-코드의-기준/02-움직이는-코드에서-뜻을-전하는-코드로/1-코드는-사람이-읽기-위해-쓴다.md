# 코드는 사람이 읽기 위해 쓴다

> [움직이는 코드에서 뜻을 전하는 코드로](./README.md)

## 빠른 복습
- **코드는 결국 사람이 읽기 위해 작성하는 것이다.**
- **단순히 코드가 짧다고 좋은 게 아니라 이해하기 쉬워야 한다.** 코드를 읽고도 **의도를 파악할 수 없다면 활용하거나 수정하기 어렵다.**
- 읽기 쉬운 쪽을 만드는 것은 세 가지다 — **함수 이름 · 조건을 표현하는 방식 · 의미가 드러나는 중간 변수**.
- 코틀린은 **`if` 와 `when` 을 문(statement)이 아니라 식(expression)으로** 취급한다. 그래서 **조건마다 평가한 결과를 변수에 대입하지 않고 그대로 반환값으로 이해**할 수 있다.

## 같은 결과, 다른 이해도

원서는 **초를 "○분 ○초" 문자열로 바꾸는 함수**를 두 가지로 보여준다. 먼저 개선 전이다.

```kotlin
fun text(x: Long): String {
    return when {
        x < 60 -> "${x}초"
        x / 60 * 60 == x -> "${x / 60} 분"
        else -> "${x / 60} 분 ${x - x / 60 * 60} 초"
    }
}
```

그리고 개선 후다.

```kotlin
fun formatTimeString(seconds: Long): String {
    val displayMinutes = seconds / 60
    val displaySeconds = seconds % 60

    return when {
        displayMinutes == 0L -> "${displaySeconds} 초"
        displaySeconds == 0L -> "${displayMinutes} 분"
        else -> "${displayMinutes} 분 ${displaySeconds} 초"
    }
}
```

> 두 코드는 **같은 결과를 반환**하나, 코드를 읽어 내려가며 **어떤 처리를 하는지 파악하기 쉬운 쪽은 두 번째 코드**다.

| 무엇이 달라졌는가 | 개선 전 | 개선 후 |
| --- | --- | --- |
| **함수 이름** | `text` — 무엇을 하는지 알 수 없다 | `formatTimeString` — 시간 문자열로 서식화한다 |
| **인자 이름** | `x` | `seconds` — 단위까지 드러난다 |
| **조건 표현** | `x / 60 * 60 == x` — 나눈 뒤 곱해서 원래 값과 비교(정수 나눗셈 성질을 읽어내야 한다) | `displaySeconds == 0L` — 초 부분이 0인가 |
| **중간 계산** | 식 안에 `x / 60`, `x - x / 60 * 60` 이 반복된다 | `displayMinutes` · `displaySeconds` 로 이름을 붙여 한 번만 계산한다 |

표를 읽는 법. 네 줄 중 **동작을 바꾼 것은 하나도 없다.** 전부 **읽는 사람을 위한 변경**이며, 그래서 이 장의 제목이 "움직이는 코드에서 뜻을 전하는 코드로"다.

> **단순히 코드가 짧다고 좋은 게 아니라 이해하기 쉬워야 한다.** **코드를 읽고도 의도를 파악할 수 없다면 코드를 활용하거나 수정하기 어렵다.** **코드의 의도를 명확하게 표현하고 누가 읽어도 이해할 수 있도록 신경 쓰자.**

이 기준은 [『아키텍트 첫걸음』 2.3의 클린 코드 다섯 기준](../../아키텍트-첫걸음/2-소프트웨어-설계/3-소프트웨어-설계-원칙과-실천-방법.md#클린-코드--다섯-가지-품질-기준) 가운데 **비중복**(같은 계산을 반복하지 않는다)과 **단정적**(필요한 것을 제 자리에 둔다)에 그대로 대응한다.

## when 식

> **코틀린에서는 `when` 으로 여러 개의 분기가 있는 조건식을 작성할 수 있다.**

같은 함수를 `if` 로 쓰면 이렇게 된다.

```kotlin
fun formatTimeString(seconds: Long): String {
    val displayMinutes = seconds / 60
    val displaySeconds = seconds % 60
    return if (displayMinutes == 0L) {
        "${displaySeconds} 초"
    } else if (displaySeconds == 0L) {
        "${displayMinutes} 분"
    } else {
        "${displayMinutes} 분 ${displaySeconds} 초"
    }
}
```

> **코틀린에서는 `if`, `when` 모두 문(statement)이 아니라 식(expression)으로 취급한다.** 그래서 **조건마다 평가한 결과를 변수 등에 대입하지 않고 그대로 반환값으로 이해**할 수 있다.

**식이라는 성질이 읽기 쉬움으로 이어진다는 점**이 요점이다. 문이라면 `var result` 를 선언하고 분기마다 대입한 뒤 마지막에 반환해야 한다. 식이면 **분기 자체가 값**이므로 중간 변수와 대입이 사라진다.
