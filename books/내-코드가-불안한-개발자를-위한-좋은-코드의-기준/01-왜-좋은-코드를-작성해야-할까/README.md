# 왜 좋은 코드를 작성해야 할까?

> [내 코드가 불안한 개발자를 위한 좋은 코드의 기준](../README.md)

## 이 장이 답하는 질문

**좋은 코드를 작성해야 하는 이유**를 먼저 못박는 장이다. 결론은 하나의 정의로 모인다.

> 이 책에서는 **유지보수성이 뛰어난 코드를 '좋은 코드'라 정의**하고, 이러한 코드를 작성하는 방법을 소개한다.

그래서 이 장은 세 가지를 순서대로 말한다. **왜 변경이 계속 필요한가 → 왜 유지보수성이 그 답인가 → 왜 그런데도 자주 희생되는가.**
