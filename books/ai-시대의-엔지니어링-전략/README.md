## 도식 표기 규칙

이 책의 그림은 두 종류다. 종류마다 재현 방식을 고정한다.

- **UI 목업**(앱 화면 배치)은 GitHub에서 그대로 유지되는 **Markdown 표**로 옮긴다. mermaid는 화면 안 요소의 상하좌우 배치를 보장하지 못한다.
	- 원서가 **음영으로 표시한 '새로 추가된 요소'** 는 **[새 요소]**라는 텍스트 표지로 구분한다.
	- 화면의 행과 열은 표의 행과 열로 대응시켜 배치 관계를 보존한다.
- **흐름·구조 도식**은 **mermaid**로 그린다. 실선 화살표는 진행 방향이다.
- 캡션은 세 갈래로 구분한다.
	- 원서 그림을 mermaid 도식으로 재현 → `*[그림 N-M] 제목*`
	- 원서 그림을 표·인용으로 옮김 → `*원서 [그림 N-M] 제목*` (그림이 아니라 **출처** 표시다)
	- 요약 과정에서 새로 그린 도식 → 번호 없이 설명 캡션만

## 인물 표기

원서는 하나의 가상 회사(Tea++)와 고정 인물로 책 전체를 끌고 간다. 인물이 나오면 원어를 함께 적는다.
