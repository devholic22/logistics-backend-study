# 7장 Archify 도식

문서 간 피드백, 설계 반례 순환, 확장 발견 흐름을 workflow로 작성했다. JSON 원본과 HTML, 본문용 SVG를 함께 보관한다.

세 도식 모두 showcase 9/9, 오류·경고 0개로 검증·deliver를 통과했다. 해시와 바이트 수는 validation-receipts.json에 기록했다. Chrome/Chromium이 없어 visual-check는 skipped이며 실제 HTML 브라우저 동작과 뷰포트·테마는 미검증이다.

본문과 도식은 한국어다. 고정 Viewer UI와 HTML lang은 영어로 표시된다.

SVG를 PNG로 렌더링해 한국어·레이블·분기와 피드백 화살표를 확인했다. 정적 SVG 검토는 HTML 브라우저 검증과 별개다.
