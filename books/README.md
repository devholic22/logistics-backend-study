## 책 사이의 연결

- WMS·ERP·OMS·TMS가 정보를 주고받는 실제 사례는 [시스템 컨텍스트 다이어그램](./아키텍트-첫걸음/3-아키텍처-설계/6-아키텍처-문서화.md#시스템-컨텍스트-다이어그램의-예)으로 구조화할 수 있다.
- 입고·출고·재고관리 KPI는 아키텍처에서 말하는 [측정 가능한 품질 속성](./아키텍트-첫걸음/3-아키텍처-설계/2-아키텍처-드라이버의-핵심-사항.md#품질-모델--측정-가능한-속성으로-정의한다)의 도메인 사례로 읽을 수 있다.
- 크로스도킹과 재고보관의 선택은 한쪽이 항상 우월한 문제가 아니라 [아키텍처 트레이드오프](./아키텍트-첫걸음/3-아키텍처-설계/1-아키텍처-설계의-주요-개념.md#아키텍처는-트레이드오프다)와 같은 판단 구조를 가진다.
