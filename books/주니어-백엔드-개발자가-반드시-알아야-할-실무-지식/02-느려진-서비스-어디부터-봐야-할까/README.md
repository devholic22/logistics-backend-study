## 추천 읽기 경로

- 이 장은 `처리량과 응답 시간 → 서버 성능 개선 기초` 순서로 읽는다. 다음 장은 DB 설계와 쿼리다.
- TPS가 떨어지고 전체 API가 느리다면 [먼저 병목을 찾는다](./2-서버-성능-개선-기초.md#먼저-병목을-찾는다)부터 확인한다.
- Trace에서 DB 구간이 길다면 DB 쿼리 개선 점검 순서로 이동한다.
- Trace에서 외부 호출이 길거나 오류가 많다면 외부 연동 점검 순서로 이동한다.
- 실제 ALB·NAT Gateway·Apache HttpClient 설정이 어떻게 맞물리는지는 동기 외부 API timeout 조정 사례에서 확인한다.
- Timeout과 재시도로 부하가 증폭된다면 Retry와 [과부하의 전형적인 증상](./2-서버-성능-개선-기초.md#과부하의-전형적인-증상)을 함께 읽는다.
