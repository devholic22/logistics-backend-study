# 기획 문서 템플릿

이 파일은 하나의 거대한 문서를 만들기 위한 양식이 아니다.
아래 세 부분을 각각 별도 문서로 복사하여 `Product Brief → PRD → Product Spec` 순서로 작성한다.
뒤 단계에서 새로 배운 사실은 앞 문서에 되돌려 반영한다.

확인하지 못한 내용은 비워 두지 말고 `가설`, `미확인`, `측정 예정`으로 표시한다.
